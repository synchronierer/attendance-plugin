# Attendance Plugin

SOL-Anwesenheits- und Aufenthaltscheck für Arcanum / Learn-Monitor.

Dieses Plugin ist für statische QR-Codes pro Lehrkraft und SOL-Bereich vorgesehen. Schülerinnen und Schüler scannen einen QR-Code, werden über ihre bestehende Arcanum-Session identifiziert und einem SOL-Bereich zugeordnet.

Status: frühe Pilotversion.
